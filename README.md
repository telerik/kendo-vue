# 🐞 Reporting Bugs

Before opening a new issue, please:

* Search the existing <a href="https://github.com/telerik/kendo-vue/issues">GitHub Issues</a>
* Check whether the issue has already been resolved in the <a href="https://github.com/telerik/kendo-vue/issues?q=is%3Aissue+is%3Aclosed">Closed Issues</a>
* Create a minimal reproducible example using <a href="https://stackblitz.com">StackBlitz</a>

When submitting a bug report, include:

* A runnable StackBlitz reproduction
* Vue version
* Kendo UI for Vue version
* Browser and operating system
* Steps to reproduce
* Expected behavior
* Actual behavior

> [!TIP]
> Issues that include a runnable StackBlitz example can usually be investigated much faster.
